# ระบบบริหารการฝึกอบรมหลักสูตร บตส.รุ่นที่ 61

เว็บแอพแบบ Mobile-First สำหรับผู้เข้าอบรมหลักสูตรผู้บังคับการตำรวจ (บตส.) รุ่นที่ 61
ประกอบด้วย **ทำเนียบรุ่น · ตารางสอน · ตารางเวร · แผงควบคุมแอดมิน**

เปิดใช้งาน: https://akadech4864.github.io/bts61/

## ทุกอย่าง deploy ผ่าน GitHub

| ส่วน | เก็บที่ | Deploy อย่างไร |
| --- | --- | --- |
| หน้าเว็บ (Vite + React + Tailwind CSS) | repo นี้ (สาธารณะ) | push เข้า `main` → GitHub Actions build → GitHub Pages |
| หลังบ้าน (Google Apps Script + Google Sheets + Google Drive) | repo ส่วนตัว `bts61-backend` | push เข้า `main` → GitHub Actions ส่งโค้ดเข้า Apps Script และอัปเดต Web App เดิม |

- ไม่ต้องเปิดหน้า Apps Script เพื่อวางโค้ดหรือกด Deploy เอง — Web App URL คงที่ (กำหนดไว้ใน [`src/config.js`](src/config.js))
- ฐานข้อมูลตั้งค่าตัวเองเมื่อถูกเรียกครั้งแรก: สร้างแท็บ `Members`, `Settings`, `DutySchedule`, `ClassSchedule`
  นำเข้ารายชื่อตั้งต้น และสร้างโฟลเดอร์ `BTS61_Photos` ใน Google Drive
- โค้ดหลังบ้านแยกไว้ใน repo ส่วนตัว เพราะมีอีเมลผู้ดูแล รหัสผ่านตั้งต้น และบัญชีรายชื่อจริง
  (ในเครื่องอยู่ที่โฟลเดอร์ `apps-script/` ซึ่ง repo นี้ไม่ติดตาม)

> **ครั้งแรกเท่านั้น:** เจ้าของบัญชี Google ต้องกดอนุญาตสิทธิ์ให้สคริปต์ 1 ครั้ง
> (เปิดโปรเจกต์ Apps Script → เลือก `setupDatabase` → Run → Review permissions → Allow)
> หลังจากนั้นไม่ต้องเข้า Apps Script อีก

> ถ้าเว้น `GAS_WEB_APP_URL` ใน `src/config.js` ให้ว่าง แอพจะเปิดใน **โหมดตัวอย่าง** (ข้อมูลสมมติ เก็บในเครื่องเท่านั้น รหัสแอดมินคือ `demo`)

## การใช้งานสำหรับแอดมิน

- เข้าเมนู **ตั้งค่า** → ใส่รหัสผ่านแอดมิน (ครั้งแรกใช้รหัสตั้งต้น แล้ว **ควรเปลี่ยนทันที**)
- เปลี่ยน/กู้คืนรหัสผ่าน: ระบบส่ง OTP 6 หลัก (อายุ 10 นาที) ไปยังอีเมลผู้ดูแลที่กำหนดตายตัวในโค้ดหลังบ้านเท่านั้น
- สวิตช์ **โหมดแก้ไขสำหรับผู้ใช้งานทั่วไป** + สิทธิ์ย่อย (เพิ่มรายชื่อ / แก้ไขข้อมูล / เปลี่ยนรูปถ่าย) มีผลกับทุกคนทันที
- จัดการ รายชื่อ / ตารางสอน / ตารางเวร ได้จากแผงควบคุม หรือพิมพ์ลง Google Sheet โดยตรงก็ได้
  (วันที่รับได้ทั้ง `2026-11-25` และ `25/11/2569`, เวลา `09:00` — เว้นช่อง `id` ว่างไว้ ระบบเติมให้เอง)
- ฟอร์มเพิ่ม/แก้ไขรายชื่อ: พิมพ์ชื่อจริงก่อน ถ้ามีในระบบแล้วจะกรอกข้อมูลเดิมให้ (รวมคำนำหน้า/ยศ)
  ถ้าเป็นคนใหม่ต้องเลือกคำนำหน้า/ยศเอง

## โครงสร้างโปรเจกต์

```
├─ src/
│  ├─ config.js            Web App URL และข้อมูลหลักสูตร
│  ├─ App.jsx              โครงแอพ + เมนูล่าง + หน้าต่างกลาง
│  ├─ pages/               ทำเนียบรุ่น / ตารางสอน / ตารางเวร / ตั้งค่า-แอดมิน
│  ├─ components/          ฟอร์ม, bottom sheet, ครอปรูป, toast ฯลฯ
│  └─ lib/                 api, store (cache), utils, โหมดตัวอย่าง
├─ public/                 ไอคอนและ manifest
├─ .github/workflows/deploy.yml   Auto-deploy หน้าเว็บขึ้น GitHub Pages
└─ apps-script/            (ไม่อยู่ใน repo นี้) โค้ดหลังบ้าน = repo ส่วนตัว bts61-backend
```

## พัฒนาบนเครื่อง

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # สร้างไฟล์สำหรับ deploy ที่โฟลเดอร์ dist/
```

## หมายเหตุด้านความเป็นส่วนตัว

เว็บแอพและ Web App URL เปิดให้ทุกคนที่มีลิงก์เข้าดูได้ (ไม่ต้องล็อกอิน) จึงควรแชร์ลิงก์เฉพาะภายในรุ่น
หน้าเว็บตั้งค่า `noindex` ไว้เพื่อไม่ให้ถูกเก็บเข้าเครื่องมือค้นหา
